* **Gridview, Splitview, and Paneview Components:** Dockview's core library provides four distinct layout managers (`Dockview`, `Gridview`, `Splitview`, and `Paneview`). The port library currently implements only the `Dockview` component, leaving out wrappers for simple grid splits, standalone splitters, and collapsible VS Code-style sidebars (`Paneview`).
* **Tab Context Menus (`getTabContextMenuItems`):** passes through `options`, but needs the `ContextMenu` module from `dockview-enterprise` — not covered by the free package (verified: menu silently absent, browser menu shows instead). Considered done.
* **Popout Window Management Configuration:** While popouts are listed as a core feature, specialized configuration callbacks for popout window lifecycle events or constraints (such as `createPopoutWindow` options or security/cross-origin hooks often required by frameworks) are not exposed in the wrapper's options API.
